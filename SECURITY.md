# Security Policy

## Reporting a vulnerability

Do **not** open a public issue for leaked credentials or private learner data.

Report security or privacy issues privately using **GitHub Security Advisories**
once the repository is hosted:

- Go to the repository → **Security** → **Advisories** → **New draft advisory**.

We will respond as soon as possible and coordinate a fix before any public
disclosure.

## Privacy expectations

- Study state is local SQLite by default.
- The project does not exfiltrate learner data.
- If you configure a remote AI vision backend, that backend's privacy posture is
  your responsibility.
